# Short tests and diagnostics

These scripts are the shorter experiments behind parts of the report. Most of them start from a saved FedAvg checkpoint, run a single federated round in a different way, and compare the result with one ordinary FedAvg round. They are slower to set up than the main experiments and each answers one narrow question, so they live here rather than in `train.py`.

Run them from the repository root. Most of them are launched by `scripts/one_round_tests.sh`, which needs the checkpoints written by `scripts/fedavg.sh`. The one-round tests score images with FID on 2,000 samples, which reads about 11 points higher than the 10,000-sample FID used elsewhere, so their numbers should only be compared with each other.

## One-round tests

| Script | Question it answers | Result in the report |
|---|---|---|
| `regmean_one_round.py` | Does one round of RegMean beat one round of FedAvg, and is the gain really from each client's own statistics? Includes the controls (shuffled Gram matrices, FedAvg scaled to RegMean's step size, timestep layers only) and the check of whether the client that owns a class denoises it better than FedAvg. | RegMean 51.72 vs FedAvg 54.89; controls 55.00–69.72 |
| `band_strength_tests.py` | Which per-band strengths and gates work best for RegMean in a single round? | Appendix, one-round table |
| `fisher_merge.py` | Does a Fisher-weighted merge (Adam second moments, uniform, per band or drift-weighted) beat FedAvg? | 57.30–60.20, all worse than FedAvg |
| `self_replay.py` | Does training clients on images generated by the global model help? | 55.56–59.49, worse than FedAvg |
| `correction_before_adam.py` | Does a SCAFFOLD-style correction added to the gradient before Adam help? | 121–429, much worse |
| `curvature_prediction.py` | Can curvature (Hessian-vector) terms predict how FedAvg's update differs from pooled training? | No: cosine with the true error about 0.003 |
| `regmean_ten_rounds.py` | Does the one-round RegMean gain hold over ten rounds? | Led FedAvg by about 13 FID after ten rounds from round 25 |

`common.py` holds the helpers these scripts share.

## Diagnostics

| Script | What it measures |
|---|---|
| `save_client_models.py` | Runs one round of local training from a checkpoint and saves every client's model. |
| `client_output_spread.py` | How far the saved client models disagree in their outputs in each timestep band (appendix, client output disagreement). Needs the models from `save_client_models.py`. |
| `band_denoising_error.py` | Denoising error of several checkpoints in each band, on the same images and noise (appendix table). |
| `shared_memorisation.py` | For the shared-image runs: is the loss on the shared images lower than on unseen test images? |

Example:

```bash
python experiments/save_client_models.py --ckpt runs/fedavg_s0_round100.pt --out runs/clients/r100
python experiments/client_output_spread.py --clients runs/clients/r100
python experiments/band_denoising_error.py --ckpts runs/fedavg_s0_round100_ema.pt runs/regmean_warm_adaptive_s0_round100_ema.pt
```
